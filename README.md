# AI-Powered-Customer-Support-Service-Automation

## Overview

The AI-Powered Customer Support & Service Automation project was developed using Salesforce Service Cloud as part of the APSCHE Salesforce Virtual Internship. The system automates customer support operations by managing customers, merchandise, orders, user cases, and knowledge articles while utilizing Salesforce automation and AI capabilities.

---

## Features

- Customer Management
- Merchandise Management
- Order Management
- User Case Management
- Validation Rules
- Record Triggered Flows
- Support Queues
- AI Summary using Prompt Builder
- Lightning Application
- Reports and Dashboards

---

## Technologies Used

- Salesforce Service Cloud
- Lightning Experience
- Flow Builder
- Prompt Builder
- Lightning App Builder
- Agentforce
